# Bible Companion 0.1.20 preview

Version 0.1.20 / build 21.

The app and Share Extension now use one reading interface: 解説 / 地図 / 人物 / 絵画. Both expose the richer static commentary, original English commentary/dictionary, entity profiles and public material cards already present in the app. Their bundled data was identical; the previous difference came from separate display paths. The existing home artwork remains, and recently opened passages/history now persist across the app, extension and restart.

Questions continue in one external service selected in settings: ChatGPT, Claude or Gemini. The question field remains visible above the keyboard. The separate first-party AI question UI and old ChatGPT logo button are removed. Existing cloud conversations remain readable, and records are not deleted merely because login expires.

ChatGPT receives a question URL when it fits; opening may start an answer. Claude and Gemini explicitly copy the complete prompt and open their base page: paste and send there. Long ChatGPT prompts use the same complete-copy fallback. Opening a URL is not proof that the provider accepted or prefilled the question. Original input remains available for retry. No app login/capability, system prompt or previous conversation is exported. No fake answer streaming is shown.

Recent passages, shared originals and external-question drafts use a separate protected App Group store, scoped by account and exact reading context. Anonymous records are not silently assigned to a later login. The selected provider is shared across screens. First-party public reading requests contain passage/translation metadata only, use the same rights-checked public projection in both targets, and invoke no AI. Old private/cloud records, corpus files, model settings, plans and credentials remain unchanged.

See [the architecture and external handoff limitations](../architecture/unified-reading.md). Native Claude/Gemini prompt prefilling, physical-device SideStore installation and external-provider answer quality are not claimed as verified. This app does not retrieve external AI answers or stream them back into its UI. Existing local records are retained; legacy cloud-data deletion is labelled separately.
