# Bible Companion 0.1.2 preview preparation

Adds Japanese AI-first reading, follow-up questions, a keyboard-safe composer, spoiler controls, owner-only red debug UI, and a bundled CC-BY-SA 4.0 people/place/occurrence index (~1.48 MB). Public-domain artwork is cached after a reviewed first download. Unknown provider usage keeps the conservative reservation; validated provider usage is settled without changing user/app limits.

The release app and Share Extension build with Xcode 26.0.1, SDK iOS 26, Swift 6. Swift 149 tests, TypeScript 623 tests, 24 design contrast pairs and two Worker runtime tests passed. The Simulator build launched and its fixture entry screen was captured. Interactive keyboard/share QA and physical device installation remain pending.

Sharing authentication is explicitly disabled in production and its migration has not been applied. The new share UI can display local metadata; AI is available in the main app. No periodic Free-account check was created. Art coverage remains partial; rare names remain English and map pins are candidates.

This is a separate 0.1.2 artifact. The 0.1.1 tag, IPA, provenance and history remain intact. See the companion provenance JSON for the new IPA hash and source file hashes. The IPA has ad-hoc signatures, not an Apple distribution profile; a device installer must re-sign it. Exact byte reproduction is not claimed.
