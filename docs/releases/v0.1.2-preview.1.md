# Bible Companion 0.1.2 preview

YouVersionから共有した箇所を、アプリで日本語のAI解説と追加質問へつなぎます。人物・地名・登場箇所の索引約1.48MBを同梱し、共有拡張でもすぐ確認できます。公開が確認された絵画は初回取得後に端末へ保存します。絵画の収録は一部で、地名の位置は同定候補です。日本語名のない項目は英語名で表示します。

質問の送信ボタンをキーボード直上に統一し、重複ツールバーによるタップの妨げを修正しました。ネタバレ防止の説明と確認、許可されたアカウントだけの赤い開発者表示を追加。実使用量を検証できた回答は精算し、確認できない場合は保守的な予約量を維持します。利用上限は変更していません。

Releaseのアプリ本体とShare ExtensionをXcode 26.0.1・iOS 26 SDK・Swift 6でビルドしました。Swift149テスト、TypeScript623テスト、デザイン24コントラスト条件と公開ソースのvalidate全項目が通過。Apple XCUITestの4ケースで送信と追加質問、キーボード表示、ネタバレ切替、通常アカウントのデバッグ非表示、人物索引、共有拡張を3回開いて戻る操作を確認しています。UIテストの通信は端末内の固定データです。実機更新と実アカウントでの最終確認は未実施です。

共有画面のAI認証は無効のままです。AI解説はメインアプリで利用してください。期限付き共有認証のmigration0023と、定期的なFree確認は実行していません。GitHubの旧runはワークフロー定義のrunner.temp参照エラーでジョブ開始前に失敗し、定義を修正しました。ワークフローは手動実行のままで、新しいクラウドCIジョブは開始していません。

IPAはadhoc署名で、インストーラーが本人のAppleアカウントで再署名する必要があります。0.1.1のIPA・タグ・履歴を保持した別の更新版です。新IPAのハッシュとソース対応はprovenance JSONを参照してください。完全なバイト一致再現は主張していません。
