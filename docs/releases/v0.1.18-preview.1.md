# Bible Companion 0.1.18 preview (build 19)

共有画面では質問欄をすぐ使え、質問と回答を時系列に積み上げます。次の質問の送信待ち、取り消し、失敗時の再試行、下書きの復帰に対応しました。初回解説は別に保持し、個人の会話と共有解説のキャッシュを分離します。

質問に関係する前の節を含める文脈選択と、質問へ直接答えて本文の確認と見立てを区別する指示を改善しました。Gemmaの実回答品質や速度を実環境で検証したという意味ではありません。バックエンドからの実際のSSEを受信し、確認前の内容と確定回答を分けて表示します。

ホーム、初回案内、共有AIの準備状態、設定の説明を改善しました。共有で開くだけではAIを自動実行しません。地図は利用者が開いた1枚だけを描画し、メモリ警告時には閉じます。報告された実機クラッシュは原因未確認であり、解消済みとは断言しません。

歴代誌上・下、エズラ記、ネヘミヤ記の人物・地名説明を647件追加し、基本説明の合計は4261件です。既存プロフィールは変更・削除せず、採用した候補をそのまま組み込みました。全登場名・全節の注解や専門家校閲の完成を意味しません。

ChatGPTボタンは表示・非表示を保存できます。本文・章節・訳名・現在の質問だけを確認後、q付きHTTPS URLでChatGPTへ渡せます。日本語・改行・記号を符号化し、長いURLは内容を切り詰めずコピーへ案内します。ブラウザ履歴等に本文・質問が残る可能性があります。入力済みで止まる場合と、回答が始まる場合があるため、単なるプリフィルとは保証しません。

今回のSimulator共有ホストではSwiftUIの公開openURL経路からSafariへ遷移できました。NSExtensionContext.openとは結果が異なります。ChatGPTアプリそのものへの起動、実機や別ホストでの同一挙動は未確認です。開けない環境向けに、URL／本文コピーと、同じログイン状態の本体設定へ10分間だけ引き継ぎ、そこで明示的に開く経路もあります。会話履歴や認証情報はURLへ含めません。正式ロゴは未採用で、サービス名の文字を表示します。

IPAはローカルのad-hoc署名で、SideStoreでの再署名が必要です。実機クラッシュ、実Gemma品質、SideStoreでの今回の実機インストールは未検証です。新規課金・権限追加・一般節注解の再生成・未統合ハーネスPR 1の追加は行っていません。
