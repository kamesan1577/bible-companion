# Bible Companion 0.1.3 preview

共有画面でも期限付きの専用認証でAI解説と追加質問を利用できます。更新後、メインアプリで一度「共有画面のAIを有効にする」を確認し、YouVersionから共有し直してください。通常のログイン用トークンを共有拡張に渡しません。共有本文の送信は本人の同意に従います。

標準解説を全ユーザーで永続キャッシュします。同じ箇所・訳・境界・設定・出典版の成功回答は再推論せず、個別質問や会話履歴は共有キャッシュへ入れません。同時アクセスも重複生成を抑止します。無料確認の期限が切れると新しい推論を停止します。12時間ごとの確認スクリプトは準備しましたが、この委任実行からは定期タスクを作成できていないため、自動更新が稼働しているとは扱えません。

読書上部の不要な宣伝文を削除し、元の共有本文と訳を解説・地図・人物・絵画・質問で参照できるようにしました。長い本文は展開できます。4タブを左右スワイプで切り替え、タブ別のスクロール位置と取得した標準解説を保持します。人物画面には日本語の標準解説を併記し、索引では同名の別IDを区別します。地名の位置は同定候補で、絵画資料の収録は一部です。

ローカル検証: TypeScript631テスト、Swift149テスト、validate全項目、アプリ本体とShare ExtensionのiOS26/Swift6 Releaseビルドが成功。XCUITest5件とライト・ダークの固定本文／質問送信を確認。UIテストの通信は固定データです。実Gemmaは隔離した認証・メモリDBから標準解説と追加質問の2回だけ呼び、約43neuronsを使用。別ユーザーの標準キャッシュ再利用は追加推論0・使用0でした。本番Worker設定・health200・未認証の共有解説401も確認しました。

全聖書の統一説明は未完成です。新しい章・節の統一形式では生成済み／検証済みとも0で、既存索引や16資料カードを全節解説と数えません。31,102節の基準に対しWEB実本文31,095節の空節・区分差も記録しています。500neurons/日を仮定した生成量の初期試算は現行出力上限に合わせた分割生成で最短813日で、内容確認期間は別です。ローカルの再開台帳・構造検査・予算制御を用意し、大量生成や課金変更は行っていません。詳細はdocs/explanation-corpus-plan.mdを参照してください。

IPAはadhoc署名で、SideStoreなどで本人のAppleアカウントによる再署名が必要です。実機への更新と実アカウントの共有動作は最終確認待ちです。過去のIPA・タグ・履歴は保持しています。
