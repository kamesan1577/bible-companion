# Bible Companion 0.1.10 preview

使徒言行録の人物・名前・場所を全28章へ拡張しました。225項目に出典付きの日本語説明を保存し、読書位置に応じて改名や後の出来事を表示します。全1,007節を照合し、911節に対応、96節は理由付き空欄としています。一般的な節注解の追加とは別のデータです。

既存カードとMapKitを維持し、92地名で地図へ進めます。4地点は固定Pleiades資料と独立照合、88地点は出典・確認状態を示した従来候補です。元から座標なし5件と、誤位置や複数比定による保留5件を区別しています。Wikipediaリンク217件を収録し、残る8件は記事未確認4・同定留保3・対応言語外1です。

共有拡張では保存済み説明と地図をカード内で読めます。Core180件とSimulator UI6件を検証し、出典リンクと配布データを読み直しています。専門家校閲、署名した実機での一連操作は未実施です。SideStoreでの再署名が必要です。

進行中の創世記データは含めません。既存の節注解、無料枠、予算、認証、隔離、質問AIの設定を変更していません。元資料の権利・出典とAI編集の区別を保持しています。
