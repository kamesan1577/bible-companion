# Bible Companion 0.1.4 preview

読書画面の標準表示を、端末に収録した出典付きの日本語説明へ変更しました。ログインや共有なしでも「保存した注解を読む」から章を選べます。通常の質問と任意のAI補足、標準回答の共有キャッシュは残しています。アプリ内AIで全書を大量生成する方式は使用しません。

MHC 2.2、JFB 3.0の英語注解とEaston 2.0.1の英語辞典を収録しました。英語原文の対応は31,102節座標中31,101、辞典は3,963見出しです。複数節で同じ原文を共有するため、各節に独立した詳細解説があるという意味ではありません。サムエル記下22:1は配布モジュールの節索引が空で、MHCでは1節を含む詩の引用が22:2側にあります。独自に付け替えて対応数を増やしていません。

日本語編集は18範囲・215節座標です。使徒18–23章には六つの章概説（212節座標）と九つの短い説明を収録し、創世記1:1、詩篇23:1、ローマ9:1も含みます。章概説は各節の独立した詳細注解とは区別します。未整備の箇所はその旨を表示し、英語原文の対応を日本語の完成数に数えません。

日本語は本文と歴史的なプロテスタント注解を比較したAI補助の編集要約で、原文・注解者の信仰的解釈・編集上の注意を区別しています。専門家監修済みとはしていません。引用と見出し35件、一次本文座標、人物ID・先行文脈を機械検証しています。機械検証は意味の正しさを保証しません。同名人物は自動で統合しません。

選択範囲に収まる日本語説明のみ表示し、章概説は章末までの選択で表示します。英語の注解全文・辞典は後の出来事を含み得るため、明示した確認後に開きます。共有元の日本語本文と訳、Liquid Glass、複数節・章跨ぎの読書は維持しています。

以前の無料契約確認の期限による推論停止とMacでの更新処理は既に撤去済みです。Workers Freeの直接利用、アプリ・ユーザー予算、認証・共有用認証の期限、同意とユーザー分離は維持しています。課金契約・新たな認証・クラウドリソース作成は行っていません。

実機用IPAはSideStore等で本人による再署名が必要です。実機での更新・実アカウントの動作確認は別途必要です。過去のIPA・タグ・履歴を保持します。

検証: Swift Core 153件、TypeScript 628件、validate全項目、デザイン契約、実機向けReleaseのアプリ本体・Share Extensionビルドが成功しました。公式ツールからの再書き出しと全書座標マップは元の監査入力とバイト一致しました。UIは固定通信データで確認しており、実アカウント接続済みの確認とは区別します。
