# Bible Companion 0.1.19 preview

Version 0.1.19 / build 20.

- Saving shared-question settings now shows progress, failure, or a confirmed local readback result. Saved consent stays in place. Share-only short-lived access renews from the shared screen within the existing login lifetime, so daily app opening is unnecessary. Logout, withdrawal and account changes stop access.
- A received partial answer survives stream interruption with an incomplete label and safe error details. Check the existing request before retrying. A sent question is no longer labelled as unsent.
- The ChatGPT button opens the existing q URL directly. The official unmodified OpenAI logo and an adjacent external-link symbol distinguish it from the normal send button. Visibility settings and accessibility labels remain available. A fallback appears only for an actual opening/URL-length failure. Repeated shared-text representations are deduplicated.
- Draft-only shares are bound to the account present when opened. They cannot silently send to a different account, including after sign-in from a signed-out state.

The new share credential schema is additive migration 0025, applied through the existing D1 dashboard Console and read back. No new plan, AI model, API key, OAuth scope or inference budget was added. Existing model, quotas, bindings, assets and data content remain unchanged. The previous 0.1.18 release is preserved.

ChatGPT may start answering immediately when the URL opens; its exact recipient behavior is controlled by ChatGPT. The URL contains the selected shared body and question and can appear in browser history. No account token, conversation history or system prompt is exported.

Local API/harness, Swift and simulator checks cover the changes; exact release-commit CI and artifact hashes accompany publication. The production Gemma interruption cause and answer quality, physical-device crash cause and physical SideStore installation remain unverified. Retaining partial text does not claim that the upstream generation failure itself has been fixed.
