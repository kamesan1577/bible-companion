# Bible Companion 0.1.11 preview

ローマ人への手紙とレビ記に、人物・名前・場所の日本語説明88項目と、ヤコブ個人を集団名から分ける文脈2件を追加しました。固定WEB英語本文で全1,292節の対応を点検し、1,132節に人物・場所のリンク、160節に理由付き空欄を記録しています。一般の全節詳細注解が完成したという意味ではありません。

Wikipediaへの84リンクを収録し、同一人物と確定できない伝承は関連記事として表示します。14件の従来地図候補は、未確認の参考位置と明示して保持。新たな確認済み座標への昇格はありません。シナイ山とシナイの荒野、族祖ヤコブとイスラエルの民、称号と個人を分け、選択箇所より先の情報は補足・出典・名前にも表示時点を設定しました。ローマ末尾のWEBと一般的な節番号の差も出典付きで記録しています。

Core188件、UI8件、既存の全体検証を通過。共有拡張の保存済み説明と地図、従来のカードとMapKitを確認しました。専門家校閲と署名済み実機確認は未実施です。SideStoreでの再署名が必要です。

使徒の既存データと節注解は保持しています。民数記・ヨシュア記の執筆中原稿、保留中の創世記・出エジプト記はこの更新に含めません。質問AI、無料枠、予算、認証、利用者間の隔離の設定変更はありません。
