# Bible Companion 0.1.21 preview

Version 0.1.21 / build 22.

The shared four-tab reader now shows a small count in each tab's upper-right corner. A nonzero artwork count makes available artwork visible before opening the tab. Zero is subdued, pending counts show an ellipsis, and unavailable counts show a dash. VoiceOver reads the exact number; values above 99 use a compact `99+` visual badge. Accessibility text sizes retain a menu with spoken counts.

Counts and visible rows use the same projection after current-passage, rights, spoiler-boundary and duplicate filtering:

- 解説: Japanese commentary cards plus one source-backed public-text/reference block when available. Empty notices, global dictionary search and English commentary behind future-content confirmation are excluded.
- 地図: displayed place material cards plus remaining unique indexed place/name rows after excluding profiles already represented by a material card. This is a count of place records, not map coordinates or pins.
- 人物: displayed person material cards plus remaining unique indexed person/name rows after the same duplicate suppression.
- 絵画: unique currently displayable artwork cards, not the number of downloaded image files.

All tab counts load on entry from the existing public reading response and lightweight bundled metadata. Only the selected tab mounts its content, so artwork images and interactive maps are not created merely to count records. Future-content toggles keep displayed lists/counts together and reset when the passage changes. Late responses cannot replace a different passage's inventory. Retrieval errors stay distinguishable from a confirmed zero.

The existing external-question handoff, protected account-scoped history/drafts, corpus and backend API are unchanged. No new inference, permission scope or data deletion is introduced. Physical-device SideStore installation and native Claude/Gemini prompt prefilling remain unverified; those services retain the explicit full-copy/manual-paste handoff.
