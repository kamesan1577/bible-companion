# Bible Companion 0.1.23 preview

Restores the platform segmented Picker used before the count badges. Removes the custom 54-point capsule, opaque selection paint and numeric/loading badges; iOS again owns the native approximately 31-point control, selection, touch and accessibility behavior. A small text dot appears only when successfully loaded content exists. Loading, unavailable and zero remain distinct in state and spoken labels.

The shared main-app/Share Extension composer now uses one compact Liquid Glass input surface, a standard circular glass send control and a small provider selector. Text grows with the draft; the keyboard leaves send reachable. A short provider/data-scope display remains. Repeated notices and the wide send bar are removed; provider-specific paste instructions appear after the relevant action.

Existing artwork catalog, public data, account-scoped drafts/history and external-provider handoff are retained. No backend deployment or data migration is needed. Physical SideStore installation remains unverified.
