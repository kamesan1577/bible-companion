# 地理カードの出典と表示範囲

確認日: 2026-10-13。対象はコリント、ケンクレア、エペソの3地点のみ。
他の箇所や全聖書の地理資料を網羅しているわけではない。

## 採用した点

| カード     | Pleiades                                          |               緯度 |               経度 | 点の意味                                                 |
| ---------- | ------------------------------------------------- | -----------------: | -----------------: | -------------------------------------------------------- |
| コリント   | [570182](https://pleiades.stoa.org/places/570182) |  37.90564164345828 | 22.878614390874485 | 古代コリント遺跡の代表点。現代のコリント市中心部ではない |
| ケンクレア | [570347](https://pleiades.stoa.org/places/570347) |           37.88239 |          22.992532 | 古代の港町の代表点。個々の出来事や建物を指さない         |
| エペソ     | [599612](https://pleiades.stoa.org/places/599612) | 37.940164271971945 |  27.34240298195866 | エフェソス遺跡の代表点。現代のセルチュク市中心部ではない |

座標値は公式データの `reprPoint` をそのまま転記した。
GeoJSON の順序は経度・緯度であり、アプリの latitude / longitude へ明示的に対応させている。
表示時の小数桁数は測量精度を意味しない。

## 再現性

Pleiades の個別ウェブページは確認時に bot 対策の画面になったため、Pleiades が公式に案内する [ISAW 公開データセット](https://github.com/isawnyu/pleiades.datasets) を利用した。
保護画面の回避や CAPTCHA の操作は行っていない。

固定したコミット: `e0ad89cad8f55ab4b85138fb4f852d9ca07b1ebc`。
`data/geography/pleiades-evidence.json` に各 JSON の固定 URL、ダウンロードしたファイルの SHA-256、著作者、協力者、代表点、位置資料の識別子と根拠を記録した。
元データ全体をアプリへ取り込まず、この3地点に必要な抜粋だけを保持する。

## 不確かさ

[Pleiades の代表点の説明](https://pleiades.stoa.org/help/representative-points)によると、代表点は関連する位置形状から計算され、必ずしも遺跡の厳密な位置と一致しない。
本アプリでは3地点とも `certainty: approximate` として扱う。

- コリント: OSM Way 224709706 に基づく遺跡の形状から得た代表点。
- ケンクレア: Johan Åhlfeldt の Digital Atlas of the Roman Empire 由来の点。
- エペソ: OSM Way 244582409 に基づく遺跡の形状から得た代表点。

位置資料の `accuracy_value` はそれぞれ 20、10、20 だが、その値を出来事の位置の誤差半径として使わない。
測地上の精度、遺跡の広がり、歴史的な場面の位置の確かさは別の問題である。
地図には現代の道路や海岸線が表示される。
特にエペソの古代の港や海岸線を現在の地図から復元したと表示してはならない。
推定航路、訪問順、3D 復元、人物の現在地・移動履歴を追加しない。

## 権利・帰属

Pleiades データは著作者に帰属し、[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) で公開されている。
ライセンス本文は `data/geography/LICENSE-Pleiades.txt` に保存した。
各カードの出典に資料タイトル、著作者、Pleiades、ライセンス、原資料へのリンクを表示する。
座標は変更せず、日本語説明は本プロジェクトが独自に作成した。原資料によるアプリの推奨を意味しない。

コリントとエペソには上流の [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) の帰属も表示する。
関連する OSM データには [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) が適用される。
元の位置資料に記載された OSM Way へのリンクもカードに保持する。
本プロジェクトのソフトウェアライセンスは、これらの第三者データを再ライセンスしない。
Apple Maps のベースマップはこの地名データと別物であり、MapKit が表示する帰属表示を隠さない。

## 検証の境界

資料の検証と JSON の整合性テストはローカルで実施できる。
iOS の実機・シミュレータで地図タイルが描画されること、VoiceOver、通信できない場合の見え方は Mac で別途確認が必要。
この調査をもってネイティブ地図の表示試験に合格したとはしない。
