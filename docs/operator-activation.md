# Freeプランでの通常運用

2026-10-15: 独自の契約証明・12時間期限・Macでの定期更新を撤去。Workers Freeの提供側日次上限と、アプリの原子的な日次予約台帳を用いる。通常利用にMacや証明更新スクリプトは不要。

本番は既存Workers Free、直接AI binding、Gemmaのみ。アプリ9,000／ユーザー2,000の日次予算を維持し、推定使用量の予約と実測の精算を行う。推定は請求上限の数学的証明とは表示しない。Freeの10,000neurons/日を超えるとCloudflare側が拒否する。Paid加入・Gateway credits・有料モデル・別プロバイダーへのフォールバックを自動で行わない。

認証、同意、ユーザー隔離、共有専用権限の期限と親セッション失効、悪用対策、出典検査は別の必要な制御として残す。UTC日次予算をまたぐ古い予約は送信に使わず、新しい日の要求は新しく予約する。これは契約証明期限ではない。

`AI_BUDGET_MODE=free-provider-hard-stop` に証明行・証明用環境変数は不要。過去の証明・スロット・履歴のDB行は監査用に保持し、変更・削除・永久有効化しない。`strict-proof` の別用途の証拠と処理は維持する。

公式仕様: https://developers.cloudflare.com/workers-ai/platform/pricing/ 。将来プランや接続経路を手動で変更する場合は、その変更の費用条件を確認する。アプリの日次予約だけを、Paid契約下のアカウント全用途に対する絶対的な課金上限とは扱わない。

以前の証明運用手順は `docs/history/operator-activation-before-certificate-removal.md` に履歴として保存した。現在のアプリ運用には適用しない。親側の定期タスクは停止済みとの報告を受領。ローカルの更新スクリプトも削除し、追加のcronや認証は作成しない。
