## ChatGPT alternative (local, incomplete direct handoff)

No official public third-party iOS question-prefill URL contract was established. No guessed `?q=` or custom scheme is used. The local candidate therefore provides an explicitly labeled preview-and-copy fallback, not direct ChatGPT opening or automatic submission. The button uses plain service-name text; an official downloadable icon was not obtained and no logo was drawn. This remains a limitation against the requested icon/direct-opening experience.

The explicit preview contains the current trimmed question, selected book/chapter/verse, reported translation (or explicitly unknown), and the original shared text, with standalone web-link lines removed. Multiple shared passages are labeled as such. Its builder accepts no conversation, account, capability, system prompt, or model settings. Questions over 2,000 UTF-16 units or shares over 20,000 are rejected without truncating. Clipboard copying happens only on the second explicit action, is local-only, expires after ten minutes, and preserves the draft. No URL contains the question or shared text.

“ChatGPTボタンを表示” is a device presentation preference, default true, stored atomically in a separate App Group Presentation folder. It is independent of account/AI consent and has no layout gap when hidden. The extension reads it at creation and when active. Failed writes are visible rather than claiming success.

Official references inspected: [OpenAI brand guidelines](https://openai.com/brand/) (direct service reference, use supplied logos unaltered; full design guide was gated); [OpenAI ChatGPT Search documentation](https://help.openai.com/en/articles/9237897-searching-the-web-with-chatgpt) (does not establish a third-party iOS prefill contract); [Apple Extension Overview](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/ExtensionOverview.html) (archived extension opening restrictions); [current NSExtensionContext.open API](https://developer.apple.com/documentation/foundation/nsextensioncontext/open(_:completionhandler:)) and the installed iOS26 SDK declaration. A DEBUG/Simulator-only explicit probe calls this public API with only the public `https://chatgpt.com/` root URL; it never sends a question and is absent from release builds. Host-specific probe results are recorded separately, not generalized to all iOS hosts/devices.
