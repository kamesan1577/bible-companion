# 歴代誌の編集資料

このフォルダーはAIが編集した日本語の原稿と、原典を照合した記録を保存します。
原稿には保留中の候補や、アプリへ採用していない説明も含みます。
アプリに表示する範囲は、公開版のentity-profiles-1CH.jsonとentity-profiles-2CH.jsonで別に定めています。

固定WEBの全1,764節に対応する原文と出現候補の照合記録は、全登場名の日本語説明や全節の詳細注解が完成したことを意味しません。
同名人物、個人名と集団名、異表記、現代所在地の不確実性は照合記録に残しています。

一次本文World English BibleはPublic Domainです。
Wikipediaなどの二次資料は各sourceのURL、ライセンス、attributionを参照してください。
CC BY-SA 4.0に由来する編集資料には同ライセンスの条件が適用されます。
コードのライセンスと第三者資料の利用条件を区別しています。

個人用の作業パスは公開用の表記に置換しています。
各ファイルの公開ハッシュと元ファイルのハッシュをpreservation-manifest.jsonに記録します。
修正前の原稿実バイトと未公開作業の履歴は、別途Libraryの再開用アーカイブに保存しています。
保存できなかった一部の中間レビュー記録は、保存済みとして扱いません。

このフォルダー内には、編集作業の手順を示す一部の補助スクリプトを参照資料として含めています。
公開用の投影スクリプト自体と修正前の実バイトは、Libraryの再開用アーカイブに保存しています。
公開用のパス置換を行っているため、そのまま本番データを更新する入口には使いません。
