# Chronicles source-coordinate map authoring

Work only on the explicit root-assigned verse-review-inputs chunk. This is entity occurrence work, not verse commentary. Read every fixed WEB verse and sufficient preceding/following context. The input rawCandidates are unverified index suggestions; neither string matching nor a current draft proves identity. Do not invent IDs, biographies, coordinates, or successful checks. Do not edit other chunks, drafts, candidate/, or the published checkout.

Write reviews/verse-map-BOOK-START-END.json. Preserve exact source input and witness SHA256. Top-level fields: book, scope {startChapter,startVerse,endChapter,endVerse,verseCount}, sourceInputPath, sourceInputSHA256, fixedWitnessPath, fixedWitnessSHA256, status=author-source-reviewed-awaiting-independent-review, reviewer=author-map-source-read, limitations, unresolvedCanonicalCandidates, verses.

One verses row per fixed coordinate, including no-link verses: {book,chapter,verse,sourceText,sourceTextSHA256,citationURL,entities:[{entityID,relationship:direct|context,reasonJa}],excludedCandidates:[{entityID,reasonJa}],reviewNoteJa}. Exact fixed source text and URL are mandatory. No duplicate coordinate or duplicate ID per row; an ID cannot be simultaneously adopted and excluded. A direct occurrence requires the corresponding exact named subject or demonstrable spelling variant at that verse. Pronouns, agents, speakers, possessors, ethnic forms, ancestry/clan/town associations require an explicit contextual reason and relationship=context where appropriate. A place coordinate is never established by an occurrence map.

Explicitly assess each raw candidate; reject wrong same-name, wrong book, wrong person/collective/territory, unsupported retrospective identity, and bad index coordinates with precise reasons. Do not silently drop a correct named occurrence. Check relevant existing IDs in the fixed entity index if input candidates omit an explicit name. If no suitable existing ID can be proved, record the term/coordinate/reason in unresolvedCanonicalCandidates. Do not convert a people into a similarly named country or person merely to obtain a link. Father/sons phrases in genealogies may express clan/town associations; preserve real interpretive uncertainty.

Read source independently of draft prose. A valid canonical source identity can be recorded even if its Chronicles profile is still being authored, but record this in unresolvedCanonicalCandidates as profile-review-pending and do not claim runtime integration or reader-gate approval. Root filters runtime eligibility only after profile and map independent reviews. No runtime activation or publication by map authors. Do not reuse a historical writer's identity verdict without checking the fixed text. No paid API/key/billing changes; GEN/EXO authoring paused.

Save actual source-check progress; do not fabricate elapsed time or checkedAt. Full chunk completion is source coverage only, not independent semantic approval.
